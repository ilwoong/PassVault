# PassVault

비밀번호·보안 메모·카드·신분증 정보를 **기기 안에서만** 암호화해 보관하는 Android 앱이다.
네트워크 권한이 아예 없고, 백업은 암호화된 파일로 직접 만든다.

> **상태**: 1차 범위 구현은 끝났다. 아직 스토어에 올리지 않았고, 독립적인 보안 감사도 받지 않았다.
> 중요한 데이터를 맡기기 전에 [위협 모델](spec/01-threat-model.md)과 아래 "알려진 한계"를 먼저 읽어 보길 권한다.

## 기능

- **항목 4종** — 로그인, 보안 메모, 카드, 신분증을 보관한다. 제목·사용자명으로 찾고 타입으로 걸러 볼 수 있으며, 자주 쓰는 항목은 즐겨찾기로 올려 둘 수 있다
- **비밀번호 규칙 기록** — 서비스마다 다른 비밀번호 규칙(최소·최대 길이, 필수·금지 문자 종류, 허용 특수문자, 변경 주기 등)을
  항목과 함께 적어 두면, 저장한 비밀번호가 그 규칙에 맞는지 알려 준다
- **잠금** — 마스터 비밀번호나 생체 인증(지문·얼굴)으로 연다. 한동안 쓰지 않거나 앱을 떠나거나 화면이 꺼지면 알아서 잠기고,
  비밀번호를 여러 번 틀리면 다시 시도하기까지 기다리는 시간이 점점 길어진다
- **화면 보호** — 스크린샷·화면 녹화·최근 앱 미리보기를 막고, 복사한 값은 클립보드에서 자동으로 지운다
- **백업과 복구** — 백업 비밀번호로 암호화한 `.pvault` 파일로 내보내고 가져온다. 다른 기기에서도 복구할 수 있다

클라우드 동기화, 자동 완성(Autofill), 비밀번호 생성기는 넣지 않았다. 이유는 [개요](spec/00-overview.md)의 비범위 표에 적어 두었다.

## 보안 설계

```
마스터 비밀번호 ──Argon2id──▶ MK ──AES-256-GCM으로 풀기──▶ VK ──▶ SQLCipher로 DB 전체 암호화
```

- 마스터 비밀번호와 MK는 어디에도 저장하지 않는다. 비밀번호가 맞는지는 GCM 태그로만 확인하고, 따로 해시를 두지 않는다
- Argon2id 파라미터는 금고를 만들 때 그 기기에서 직접 재서 정한다 (메모리 32~64 MiB, 반복 3~8회)
- 생체 인증이 마스터 비밀번호를 대신하는 것은 아니다. Android Keystore의 키로 VK를 한 번 더 감싸 둘 뿐이고,
  생체 정보가 새로 등록되면 그 키는 못 쓰게 된다
- 백업 파일은 기기 키에 묶이지 않는다. 백업 비밀번호에서 따로 유도한 키로 암호화하기 때문이다
- 권한을 선언하지 않는다. `INTERNET`도 없다. 기기 백업이나 기기 간 전송에도 앱 데이터가 실리지 않게 해 두었다
- "잠겼다"는 것은 VK가 메모리에 없고 DB가 닫혀 있다는 뜻이다. 화면만 가려 두는 잠금이 아니다

더 자세한 내용은 [암호화 설계](spec/02-crypto.md), [잠금 정책](spec/06-lock-policy.md), [백업](spec/07-backup.md)에 있다.

### 알려진 한계

- **마스터 비밀번호를 잊으면 복구할 수 없다.** 백도어가 없어서, 되살릴 수단은 백업 파일뿐이다
- 루팅된 기기, 관리자 권한을 얻은 멀웨어, 키로거나 악성 접근성 서비스는 막지 못한다
- 메모리 포렌식도 막지 못한다. 키와 비밀번호는 쓰고 나서 바로 지우지만, JVM에서는 완전히 보장할 수 없다
- 시스템 클립보드는 정해 둔 시간이 지나면 비우지만, 키보드 앱이 따로 보관하는 클립보드 기록까지는 지울 수 없다
- 잠금 해제 화면의 "백업 파일에서 복구"는 인증 없이도 기존 금고를 다른 백업으로 덮어쓸 수 있다
  (비밀번호를 잊은 사용자를 위한 출구라 인증을 요구할 수 없다). 다만 기존 비밀이 드러나지는 않는다

## 빌드

JDK 17 이상과 Android SDK 36이 필요하다. Android Studio에서 열거나 명령줄에서 빌드하면 된다.

```bash
./gradlew :app:assembleDebug            # 디버그 APK
./gradlew :app:testDebugUnitTest        # JVM 단위 테스트
./gradlew :app:connectedDebugAndroidTest  # 계측 테스트 (기기나 에뮬레이터 필요)
```

- 최소 Android 9 (API 28)
- 디버그 빌드는 패키지 이름에 `.debug`가 붙어서 릴리스 빌드와 나란히 설치할 수 있다
- 릴리스 빌드(`:app:assembleRelease`)는 R8로 축소·난독화된다. **서명 설정은 저장소에 없으니** 직접 서명해야 한다
- 암호화·DB·생체 테스트는 실제 구현 위에서 돌려야 의미가 있어서 계측 테스트로 두었다. 생체 테스트 일부는 기기에 지문이 등록돼 있어야 한다
