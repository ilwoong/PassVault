# PassVault

비밀번호·보안 메모·카드·신분증 정보를 **기기 안에서만** 암호화해 보관하는 Android 앱.
네트워크 권한이 없고, 백업은 암호화된 파일로 직접 만든다.

> **상태**: 1차 범위 구현 완료. 스토어에 배포하지 않았고 독립적인 보안 감사를 받지 않았다.
> 중요한 데이터를 맡기기 전에 [위협 모델](spec/01-threat-model.md)과 아래 "알려진 한계"를 읽어 보기를 권한다.

## 기능

- **항목 4종** — 로그인, 보안 메모, 카드, 신분증. 제목·사용자명 검색과 타입 필터, 즐겨찾기
- **비밀번호 규칙 기록** — 서비스마다 다른 비밀번호 규칙(최소·최대 길이, 필수·금지 문자 종류, 허용 특수문자, 변경 주기 등)을
  항목과 함께 적어 두고, 저장한 비밀번호가 그 규칙을 지키는지 표시한다
- **잠금** — 마스터 비밀번호, 생체 인증(지문·얼굴), 유휴·백그라운드·화면 꺼짐 자동 잠금, 실패 횟수에 따른 대기
- **화면 보호** — 스크린샷·화면 녹화·최근 앱 미리보기 차단, 클립보드 자동 삭제
- **백업과 복구** — 백업 비밀번호로 암호화한 `.pvault` 파일로 내보내고 가져온다. 다른 기기에서도 복구할 수 있다

클라우드 동기화, 자동 완성(Autofill), 비밀번호 생성기는 없다. 제외한 이유는 [개요](spec/00-overview.md)의 비범위 표에 있다.

## 보안 설계

```
마스터 비밀번호 ──Argon2id──▶ MK ──AES-256-GCM 언래핑──▶ VK ──▶ SQLCipher 로 DB 전체 암호화
```

- 마스터 비밀번호와 MK 는 저장하지 않는다. 검증 수단은 GCM 태그뿐이며 별도의 해시를 두지 않는다
- Argon2id 파라미터는 금고를 만들 때 기기에서 측정해 정한다 (메모리 32~64 MiB, 반복 3~8회)
- 생체 인증은 마스터 비밀번호를 대신하지 않는다. Android Keystore 의 키로 VK 를 한 번 더 감싸 둘 뿐이며,
  생체 정보가 새로 등록되면 그 키는 무효가 된다
- 백업 파일은 기기 키에 묶이지 않는다. 백업 비밀번호에서 따로 유도한 키로 암호화한다
- 권한을 선언하지 않는다. `INTERNET` 도 없다. 기기 백업·기기 간 전송에서도 앱 데이터를 제외한다
- 잠겨 있다는 것은 VK 가 메모리에 없고 DB 가 닫혀 있다는 뜻이다. 화면만 가리는 잠금이 아니다

자세한 내용은 [암호화 설계](spec/02-crypto.md), [잠금 정책](spec/06-lock-policy.md), [백업](spec/07-backup.md).

### 알려진 한계

- **마스터 비밀번호를 잊으면 복구할 수 없다.** 백도어가 없다. 되살릴 수단은 백업 파일뿐이다
- 루팅된 기기, 관리자 권한 멀웨어, 키로거·악성 접근성 서비스는 막지 못한다
- 메모리 포렌식은 막지 못한다. 키와 비밀번호를 쓰고 바로 지우지만 JVM 에서 완전한 보장은 없다
- 클립보드: 시스템 클립보드는 지정 시간 뒤 비우지만, 키보드 앱이 따로 보관하는 클립보드 기록은 지울 수 없다
- 잠금 화면의 "백업 파일에서 복구"는 인증 없이 기존 금고를 다른 백업으로 덮어쓸 수 있다
  (비밀번호를 잊은 사용자의 출구라 인증을 요구할 수 없다). 기존 비밀이 드러나지는 않는다

## 빌드

요구 사항: JDK 17 이상, Android SDK 36. Android Studio 에서 열거나 명령줄에서:

```bash
./gradlew :app:assembleDebug            # 디버그 APK
./gradlew :app:testDebugUnitTest        # JVM 단위 테스트
./gradlew :app:connectedDebugAndroidTest  # 계측 테스트 (기기나 에뮬레이터 필요)
```

- 최소 Android 9 (API 28)
- 디버그 빌드는 패키지 이름에 `.debug` 가 붙어 릴리스 빌드와 함께 설치된다
- 릴리스 빌드(`:app:assembleRelease`)는 R8 로 축소·난독화되며 **서명 설정이 저장소에 없다.** 직접 서명해야 한다
- 암호화·DB·생체 테스트는 실제 구현 위에서 돌아야 의미가 있어 계측 테스트로 두었다. 생체 테스트 일부는 기기에 등록된 지문이 필요하다
