# 00. 제품 개요

## 한 줄 정의

사용자의 비밀번호·보안 메모·카드·신분증 정보를 **기기 안에서만** 암호화해 보관하는 Android 앱.
마스터 비밀번호 하나로 금고를 열고, 암호화된 파일로 수동 백업한다.

## 범위 (1차 버전에 포함)

| ID | 기능 | 상세 스펙 |
|----|------|-----------|
| F-01 | 마스터 비밀번호로 금고 생성·잠금 해제 | [02](02-crypto.md), [05](05-ui-flows.md) |
| F-02 | 항목 4종 CRUD (로그인 / 보안 메모 / 카드 / 신분증) | [03](03-data-model.md), [05](05-ui-flows.md) |
| F-03 | 제목·사용자명 기준 검색, 타입 필터 | [05](05-ui-flows.md) |
| F-04 | **비밀번호 정책 기록 + 준수 검사** — 각 서비스가 요구하는 규칙(최소 길이, 필수 문자 종류, 허용/금지 특수문자, 변경 주기 등)을 항목에 함께 저장하고, 저장된 비밀번호가 그 규칙을 만족하는지 표시 | [03](03-data-model.md#비밀번호-정책), [05](05-ui-flows.md) |
| F-05 | 생체 인증 잠금 해제 (지문·얼굴) | [02](02-crypto.md#생체-해제), [06](06-lock-policy.md) |
| F-06 | 자동 잠금 (유휴 타임아웃 / 백그라운드 전환) | [06](06-lock-policy.md) |
| F-07 | 화면 보호 (스크린샷·최근앱 미리보기 차단, 클립보드 자동 삭제) | [06](06-lock-policy.md) |
| F-08 | 암호화 파일로 수동 백업 / 복구 (SAF) | [07](07-backup.md) |
| F-09 | 마스터 비밀번호 변경 | [02](02-crypto.md#마스터-비밀번호-변경) |
| F-10 | 설정 (자동 잠금 시간, 생체 토글, 클립보드 삭제 시간) | [05](05-ui-flows.md) |

## 비범위 (1차에서 **의도적으로** 제외)

제외 이유를 남기는 이유: 나중에 "왜 없지?"라고 다시 묻지 않기 위해서다.
구현 중 이 목록에 있는 기능을 "있으면 좋으니까" 추가하지 않는다.

| 제외 항목 | 이유 | 재검토 시점 |
|-----------|------|-------------|
| 클라우드 동기화 | 네트워크 권한 자체를 갖지 않는 것이 공격면·스펙 크기 양쪽에서 유리. E2E 동기화는 키 공유·충돌 해결 스펙이 별도로 필요 | 2차 |
| Autofill 서비스 | `AutofillService` 구현은 난도와 기기별 편차가 큼. 금고 자체가 먼저 안정화돼야 함 | 2차 |
| 비밀번호 생성기 | 사용자가 1차 범위로 선택하지 않음. F-04 정책 기록과 결합하면 자연스러운 후속 기능 | 2차 |
| 첨부파일 (사진·문서) | 바이너리 암호화 스트리밍·용량 관리 스펙이 추가로 필요 | 3차 |
| 폴더 / 태그 / 다중 금고 | 1차 데이터량에서 검색 + 타입 필터로 충분 | 필요해지면 |
| 항목 공유, 다중 사용자 | 로컬 전용 제품에 해당 없음 | 없음 |
| 유출 비밀번호 검사 (HIBP 등) | 네트워크 필요 | 2차 |
| 휴지통 / 변경 이력 | 삭제는 즉시 영구 삭제. 되돌리기는 백업 파일로 | 필요해지면 |

## 비기능 요구사항

| ID | 항목 | 기준 |
|----|------|------|
| NFR-01 | 잠금 해제 소요 시간 | 중급 기기에서 Argon2id 1회 포함 **1.5초 이하**. 이 값이 [02](02-crypto.md)의 KDF 파라미터 상한을 결정한다 |
| NFR-02 | 항목 1,000개에서 목록·검색 응답 | 100ms 이하 (비밀 필드는 목록에서 복호화하지 않음) |
| NFR-03 | 권한 | **런타임 권한 0개.** 인터넷 권한도 선언하지 않는다 |
| NFR-04 | 오프라인 | 네트워크 없이 모든 기능 동작 |
| NFR-05 | 데이터 손실 | 마스터 비밀번호 분실 시 복구 불가. 온보딩에서 명시적으로 고지하고 확인받는다 ([05](05-ui-flows.md)) |

## 용어

| 용어 | 의미 |
|------|------|
| **금고 (Vault)** | 암호화된 데이터 저장소 전체. 앱에 금고는 하나다 |
| **항목 (Entry)** | 금고에 저장되는 한 건. 타입 4종 중 하나를 가진다 |
| **MK (Master Key)** | 마스터 비밀번호에서 Argon2id로 유도한 키. 저장하지 않는다 |
| **VK (Vault Key)** | DB를 실제로 암호화하는 랜덤 키. MK로 래핑되어 저장된다 |
| **래핑 (Wrapping)** | 키를 다른 키로 암호화해 보관하는 것 |
| **잠금 / 해제** | VK가 메모리에 없는 상태 / 있는 상태. 자세한 정의는 [06](06-lock-policy.md) |
| **비밀 필드** | 비밀번호, 카드번호, CVC, 신분증 번호, 메모 본문. 목록 화면에 절대 노출하지 않는 필드 |
