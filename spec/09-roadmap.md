# 09. 구현 로드맵

각 마일스톤은 **검증 기준을 통과할 때만** 완료다. 순서를 건너뛰지 않는다 —
아래 순서는 "뒤 단계가 앞 단계의 결정에 의존하는" 순서다.

> 다음에 할 일을 고를 때는 이 문서의 가장 위에 있는 미완료 마일스톤을 택한다.

---

## M0 — 프로젝트 골격

**산출물**: 빈 Compose 앱, version catalog, Hilt 배선, 패키지 구조([ARC-02](04-architecture.md)) 생성, 매니페스트 보안 설정([ARC-07](04-architecture.md)).

- `applicationId` = `com.beginkub.passvault` 적용 ([ARC-07](04-architecture.md))
- `allowBackup=false`, `dataExtractionRules`, 권한 0개
- `MainActivity` 에 `FLAG_SECURE` ([LOCK-06](06-lock-policy.md))

**검증**
- [ ] 실기기에 설치·실행된다
- [ ] [TST-13](08-testing.md) 매니페스트 검증 통과

---

## M1 — 암호화 기반

**산출물**: `security/` 패키지 전체 — `Argon2KeyDeriver`, `AesGcmKeyWrapper`, `VaultMetaStore`, `VaultKeyManager`, `Secrets`.
UI는 아직 없다. 테스트로만 구동한다.

**참조**: [CRY-01~CRY-04](02-crypto.md), CRY-09~CRY-11, CRY-16, [DM-01](03-data-model.md)

**검증**
- [ ] [TST-01](08-testing.md) 라운드트립·변조 검출 전부 통과
- [ ] [TST-04](08-testing.md) 제로화 통과
- [ ] [TST-10](08-testing.md) 실기기에서 캘리브레이션 결과가 NFR-01 충족
- [ ] `vault_meta` 원자적 교체 확인 ([TST-03](08-testing.md) 프로세스 종료 케이스)

---

## M2 — 암호화 DB와 데이터 모델

**산출물**: Room + SQLCipher 연결, 엔티티·DAO·Repository, 정책 평가기(`data/policy`).

**참조**: [CRY-05](02-crypto.md), [DM-03~DM-12](03-data-model.md)

**검증**
- [ ] [TST-05](08-testing.md) DB 파일에 평문·SQLite 매직이 없다 ← **이 단계의 핵심 검증**
- [ ] [TST-06](08-testing.md) CRUD·CASCADE·외래키 활성 확인
- [ ] [TST-02](08-testing.md) 정책 평가 표 기반 테스트 전부 통과
- [ ] [TST-07](08-testing.md) 캐시 컬럼 불변식 통과

> 정책 평가기를 UI보다 먼저 만드는 이유: 순수 함수라 테스트가 빠르고,
> [UX-07](05-ui-flows.md)의 실시간 피드백이 이것에 의존한다.

## M3 — 세션과 잠금 해제 플로우

**산출물**: `SessionManager` 상태머신, 온보딩 화면, 잠금 해제 화면, 백오프.

**참조**: [LOCK-01~LOCK-05](06-lock-policy.md), [UX-01](05-ui-flows.md), UX-02

**검증**
- [ ] 앱 재시작 후 저장한 금고가 열린다
- [ ] [TST-08](08-testing.md) 백오프·시간 조작 우회 불가 통과
- [ ] 잠금 시 DB 핸들 닫힘 + VK 제로화 확인
- [ ] 온보딩에서 복구 불가 경고 확인 없이는 진행 불가 (NFR-05)

---

## M4 — 항목 CRUD UI

**산출물**: 목록(검색·필터), 상세(마스킹·복사), 편집 화면 4종.
정책 섹션은 아직 비워 둔다 (M5).

**참조**: [UX-04~UX-06](05-ui-flows.md), UX-13

**검증**
- [ ] [TST-14](08-testing.md) 핵심 플로우·마스킹·목록에 비밀 없음 통과
- [ ] 항목 1,000건 더미 데이터로 목록·검색이 NFR-02(100ms) 충족
- [ ] 타입 4종 모두 생성·수정·삭제 가능

---

## M5 — 비밀번호 정책 기록과 준수 검사

**산출물**: 정책 편집 섹션, 상세 화면의 위반 표시, 목록 경고 배지, 포그라운드 복귀 시 `hasRotationDue` 일괄 재계산.

**참조**: [DM-08~DM-10](03-data-model.md), [UX-07](05-ui-flows.md)

**검증**
- [ ] 정책 미입력 항목에 아무 표시도 나타나지 않는다
- [ ] 모든 규칙을 `모름`으로 둔 정책이 위반을 만들지 않는다
- [ ] 위반 종류별로 상세 화면에 올바른 문구가 뜬다
- [ ] 정책 입력 중 실시간 피드백이 동작한다
- [ ] 목록 배지가 캐시 컬럼만 읽는다 (비밀번호 복호화 호출이 없음을 코드로 확인)
