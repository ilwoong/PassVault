# 09. 구현 로드맵

각 마일스톤은 **검증 기준을 통과할 때만** 완료다. 순서를 건너뛰지 않는다 —
아래 순서는 "뒤 단계가 앞 단계의 결정에 의존하는" 순서다.

> 다음에 할 일을 고를 때는 이 문서의 가장 위에 있는 미완료 마일스톤을 택한다.

**현재 상태**: 구현은 M9 까지 끝났고 실기기 확인도 마쳤다. `[ ]` 로 남은 것은 **저사양 기기**의 해제 시간 하나다
([10](10-traceability.md) 의 수기 체크리스트 결과 참조). 구현 작업이 아니며, 저사양 기기를 구하면 닫는다.
마일스톤 밖에서 남은 일은 문서 끝의 [남은 일](#남은-일-1차-범위-안)에 있다.

## M0 — 프로젝트 골격

**산출물**: 빈 Compose 앱, version catalog, Hilt 배선, 패키지 구조([ARC-02](04-architecture.md)) 생성, 매니페스트 보안 설정([ARC-07](04-architecture.md)).

- `applicationId` = `io.github.ilwoong.passvault` 적용 ([ARC-07](04-architecture.md))
- `allowBackup=false`, `dataExtractionRules`, 권한 0개
- `MainActivity` 에 `FLAG_SECURE` ([LOCK-06](06-lock-policy.md))

**검증**
- [x] 실기기에 설치·실행된다 — Galaxy S23 (SM-S911N, Android 16), 난독화 릴리스 빌드

## 남은 일 (1차 범위 안)

마일스톤 검증 기준에는 없지만 배포 전에 닫아야 하는 것들. 끝내면 지운다.

### 결정이 필요한 것

- `TODO(결정필요):` **자동 잠금 15초에서는 백업을 사실상 할 수 없다.** 파일 선택기에 15초 넘게 머물면 돌아오자마자
  유휴 판정으로 잠긴다 ([LOCK-03](06-lock-policy.md) 의 SAF 예외는 백그라운드 즉시 잠금만 보류한다).
  선택지: ① 그대로 둔다(스펙대로다. 백업할 때는 자동 잠금 시간을 늘리라고 안내) ② 선택기가 떠 있는 동안 유휴 판정도
  보류한다(선택기를 띄운 채 자리를 비우면 돌아올 때까지 금고가 열려 있다) ③ 유휴 판정에 상한을 둔 보류(예: 5분).

### 구현

- [ ] [TST-14](08-testing.md) 의 "핵심 플로우"와 "잠금 시 화면 전환"을 자동 테스트로. 지금은 커밋되지 않은 기기 스크립트로만 확인했다
- [ ] 재인증 대화상자와 비밀번호 변경 화면의 대기 시간 카운트다운. 지금은 남은 시간이 고정으로 보이고, 화면을 나갔다
  들어와야 다시 시도할 수 있다 (해제 화면은 카운트다운한다 — UX-02)

### 직접 확인

- [ ] 저사양 실기기에서 해제 1.5초 (NFR-01)
- [ ] 키보드 앱의 클립보드 기록에 복사한 값이 남는지 (삼성 키보드 등). 남는다면 앱이 지울 수단은 없다 — LOCK-07 의 한계
- [ ] 실제 지문으로 생체 등록·해제·지문 추가 후 무효화. 에뮬레이터의 가상 지문으로만 확인했다
- [ ] 새 화면(남색 팔레트, 타입 아이콘)과 런처 아이콘을 실기기에서. 에뮬레이터에서만 봤다

### 배포 준비 (스펙 범위 밖)

- [ ] 배포용 서명 키와 서명 설정. 지금까지 릴리스 APK 는 디버그 키로 서명해 테스트했다
