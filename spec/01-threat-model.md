# 01. 위협 모델과 보안 요구사항

구현 판단이 갈릴 때 이 문서가 기준이다. "더 안전하게"가 아니라 "이 위협을 막는가"로 판단한다.

## 보호 대상

| 등급 | 자산 | 비고 |
|------|------|------|
| 치명 | 비밀 필드 평문 (비밀번호, 카드번호, CVC, 신분증 번호, 메모 본문) | 유출 시 피해 복구 불가 |
| 치명 | 마스터 비밀번호, MK, VK | 하나라도 유출되면 금고 전체가 열림 |
| 높음 | 메타데이터 (서비스명, 사용자명, URL, 항목 수, 수정 시각) | 평문 비밀번호는 아니지만 표적 공격의 재료 |
| 중간 | 설정값 (자동 잠금 시간, 생체 사용 여부) | 비밀 아님 |

## 공격자 가정

### 방어 대상 (In scope)

| ID | 위협 | 대응 요구사항 |
|----|------|---------------|
| T-01 | 잠긴 기기를 분실·도난 | SEC-01, SEC-02 |
| T-02 | **잠금 해제된** 기기를 잠깐 남에게 넘겨줌 (화면 훔쳐보기 포함) | SEC-05, SEC-06, SEC-07 |
| T-03 | 같은 기기의 다른 앱이 파일·클립보드·화면을 읽으려 함 (비루팅) | SEC-03, SEC-08, SEC-07 |
| T-04 | DB 파일만 기기 밖으로 빠져나감 (ADB 백업, 기기 백업, 포렌식 이미지) | SEC-01, SEC-03 |
| T-05 | 백업 파일이 클라우드 드라이브·메신저를 통해 유출 | SEC-04 |
| T-06 | 마스터 비밀번호에 대한 오프라인 무차별 대입 | SEC-02 |
| T-07 | 기기 UI에서의 비밀번호 추측 (온라인 대입) | SEC-09 |
| T-08 | 로그·크래시 리포트·디버그 출력에 비밀이 섞여 나감 | SEC-10 |
| T-09 | 생체 정보가 추가 등록되어 제3자가 생체 해제 사용 | SEC-11 |

### 방어 대상 아님 (Out of scope)

막지 못하는 것을 분명히 해 둔다. 이 항목들에 대응하는 코드를 넣지 않는다.

| 위협 | 이유 |
|------|------|
| 루팅·탈옥된 기기, 관리자 권한 멀웨어 | OS 신뢰 경계가 무너진 상태. 앱 단독 방어 불가. 루팅 탐지는 우회가 쉬워 비용 대비 효과가 없다 |
| 키로거, 화면 녹화 악성 접근성 서비스 | 위와 동일 |
| 메모리 덮어쓰기 / 콜드부트 / JTAG 등 하드웨어 포렌식 | JVM 환경에서 평문 키의 메모리 잔류를 완전히 제거할 수 없다. SEC-12로 **완화만** 한다 |
| OS·하드웨어·Keystore 자체 취약점 | 플랫폼 신뢰 전제 |
| 공급망 공격 (의존성 변조) | 의존성 최소화와 버전 고정으로 완화하되 방어 요구사항으로 두지 않는다 |
| 사용자가 약한 마스터 비밀번호를 고집 | 강도 표시와 최소 길이로 완화. 최종 책임은 사용자 |
| 사용자가 평문을 직접 다른 앱에 붙여넣기 | 사용자의 명시적 행동 |

## 보안 요구사항

| ID | 요구사항 | 검증 |
|----|----------|------|
| SEC-01 | 비밀 데이터는 **평문으로 디스크에 쓰이지 않는다.** DB 파일 전체가 암호화된다 | [TST-05](08-testing.md) |
| SEC-02 | 마스터 비밀번호에서 키를 유도할 때 메모리-하드 KDF(Argon2id)를 쓴다. 파라미터는 NFR-01 한도 안에서 최대로 | [CRY-02](02-crypto.md) |
| SEC-03 | 앱은 `allowBackup=false`, `android:dataExtractionRules` 로 기기 백업·전송에서 자신을 제외한다 | [TST-13](08-testing.md) |
| SEC-04 | 백업 파일은 사용자가 입력한 백업 비밀번호로 독립 암호화된다. 기기 키에 의존하지 않는다(기기 교체 시 복구 가능해야 하므로) | [BK-02](07-backup.md) |
| SEC-05 | 유휴 타임아웃과 백그라운드 전환 시 자동으로 잠긴다 | [LOCK-03](06-lock-policy.md) |
| SEC-06 | 모든 Activity에 `FLAG_SECURE`. 스크린샷·화면 녹화·최근앱 미리보기를 차단한다 | [LOCK-06](06-lock-policy.md) |
| SEC-07 | 클립보드 복사는 민감 플래그를 붙이고 일정 시간 후 자동 삭제한다 | [LOCK-07](06-lock-policy.md) |
| SEC-08 | 외부에 노출되는 컴포넌트를 두지 않는다 (`exported=false`, Content Provider·Deep link 없음) | [TST-13](08-testing.md) |
| SEC-09 | 잠금 해제 실패 횟수에 따라 지연 백오프를 적용한다. (데이터 자동 파기는 하지 않는다 — 오조작 피해가 더 크다) | [LOCK-05](06-lock-policy.md) |
| SEC-10 | 릴리스 빌드에서 비밀·키·평문을 로그에 남기지 않는다. 비밀을 담는 타입은 `toString()`을 마스킹한다 | [TST-12](08-testing.md) |
| SEC-11 | 생체 정보가 추가 등록되면 생체 해제용 Keystore 키를 무효화한다 (`setInvalidatedByBiometricEnrollment(true)`). 이후 마스터 비밀번호로만 해제 | [CRY-08](02-crypto.md) |
| SEC-12 | 키 바이트는 `ByteArray`로 다루고 사용 후 즉시 0으로 채운다. 비밀을 `String`에 담지 않는다 (완화 조치이며 완전한 보장은 아님 — Out of scope 참고) | [TST-04](08-testing.md) |
