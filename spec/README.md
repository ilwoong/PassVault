# PassVault 스펙

Android 로컬 전용 암호화 금고 앱. 이 폴더가 구현의 단일 기준(single source of truth)이다.
코드와 스펙이 어긋나면 **스펙을 먼저 고치고** 코드를 맞춘다.

구현 절차 그대로 번호가 붙어 있다. 앞 문서의 결정이 뒤 문서의 전제가 된다.

## 문서 규약

- **요구사항 ID**: `SEC-03` 처럼 접두어 + 2자리. 한 번 부여한 ID는 재사용하지 않는다.
  요구사항이 폐기되면 지우지 않고 `(폐기: 이유)`를 붙인다.
- **결정 기록**: 선택지가 둘 이상이었던 지점은 각 문서 끝의 "검토 후 제외한 대안"에 이유와 함께 남긴다.
  같은 논의를 반복하지 않기 위한 장치다.
- **미결정**: 확정 안 된 항목은 `TODO(결정필요):` 로 표시하고 임의로 메우지 않는다.
- **버전·수치**: 라이브러리 버전은 스펙에 적지 않는다. `gradle/libs.versions.toml` 이 기준이다.
  암호화 파라미터처럼 보안에 영향을 주는 수치는 반드시 스펙에 적는다.

## 커밋 규칙

구현 커밋 메시지에는 근거가 된 요구사항 ID를 적는다. 예: `feat(crypto): Argon2id 키 유도 (CRY-01, CRY-02)`
